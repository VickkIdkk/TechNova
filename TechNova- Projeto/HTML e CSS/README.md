# Nova Vida Tech — código organizado

Esta versão mantém a estrutura do site e organiza os arquivos HTML, CSS e JavaScript
com indentação e comentários explicativos.

## Organização
- `index.html` — página inicial e carrossel.
- Demais arquivos `.html` — páginas internas.
- `css/styles.css` — estilos e responsividade.
- `js/main.js` — interações, carrinho, favoritos, formulários, chat e pagamento demonstrativo.

A alteração desta versão é de organização/comentários do código; não foram adicionadas
novas funcionalidades ao site.
